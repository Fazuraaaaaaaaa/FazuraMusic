# Website Streaming Music - Menggunakan YouTube Music API

Ini adalah aplikasi web sederhana untuk melakukan streaming musik menggunakan **YTMusicAPI** dan **yt-dlp**, dengan antarmuka bergaya Spotify.

## Prasyarat Utama
- Python 3 telah terinstal di komputer Anda.
- Modul Python (Flask, ytmusicapi, yt-dlp, flask-cors) terinstal.

## Cara Menggunakan

1. **Jalankan Aplikasi:**
   - Buka terminal/command prompt di dalam folder proyek ini.
   - Jalankan perintah:
     ```bash
     npm start
     ```
     *(atau `python app.py`)*
   - Buka browser Anda dan kunjungi `http://localhost:3000`.

2. **Cara Kerja Aplikasi:**
   - Aplikasi akan otomatis menampilkan lagu-lagu Trending Indonesia.
   - Anda dapat mencari lagu di kotak pencarian.
   - Klik play pada lagu untuk memutar, buat playlist kustom, dan tambahkan lagu favorit Anda ke dalam playlist secara gratis.
